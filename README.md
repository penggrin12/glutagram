# GlutaGram

> Gluta is short for monosodium glutamate, which is E621.

An asynchronous Telegram bot that periodically fetches images
from e621 and forwards them to configured chats or channels.

Uses [aioe621](https://github.com/penggrin12/aioe621) to fetch posts,
and [aiogram 3](https://github.com/aiogram/aiogram) to post them.
